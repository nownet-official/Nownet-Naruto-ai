# NOWNET AI — Tsume Inuzuka Edition

Emotional roleplay chat with **fixed Tsume Inuzuka appearance**.

## Important

- Appearance is **permanently locked** to the Tsume Inuzuka form (the MMD model).
- All dress sets have been removed. She never changes clothes.
- Detailed adult body description is included in her fixed identity.
- The 3D PMX model files are included in `assets/model/`.
- The live avatar panel currently uses emotion-driven reaction (emoji + glow + movement). Full browser 3D MMD rendering is heavy and not fully activated yet for mobile stability.

## How to update on GitHub

1. Overwrite the old `index.html` with the new one.
2. Upload the `.nojekyll` file if it is missing.
3. Keep the existing `assets/model/` folder (do not delete it).
4. Wait 1–2 minutes, then hard-refresh the site (Ctrl+Shift+R).
